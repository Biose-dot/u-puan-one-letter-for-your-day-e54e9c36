Entry for the [make.fun](https://make.fun) bounty
[One Letter for Your Day](https://make.fun/c/u-puan-one-letter-for-your-day-e54e9c36).

Exactly one letter, A to Z, standing for the word that describes your day. Z is the sound of a day ending on zero sleep — the only letter that is already a word for how the day felt.

`main.py` (Python 3) writes the entry to `/output/entry.txt`:

> Z

Run it locally with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
